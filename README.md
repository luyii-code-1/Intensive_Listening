# Intensive Listening Web Player (精听在线播放器)

这是一个完全运行在浏览器端的 **Intensive Listening 在线版 HTML 播放器**，完整复刻了 Dart / Flutter 学生端播放器的设计风格（Windows Fluent Design）、交互逻辑与练习机制，并且深度适配移动端。

## 🌟 功能特性

### 1. 深度复刻 Dart 客户端与 Windows 11 WinUI 3 风格
- **Mica 质感与分层表面**：
  - 应用底色融合 Windows 11 Mica 柔和径向天光渐变，明亮模式与暗黑模式均呈现柔和通透感。
  - 双层物理投影系统（Ambient + Key elevation shadow），卡片具备精巧的高光斜切顶边（Light/Dark Inset Bevel）。
- **WinUI 3 动态系统与曲线 (Motion System)**：
  - 采用系统级减速与弹簧动效（Decelerate `cubic-bezier(0.1, 0.9, 0.2, 1)` 与 Spring `cubic-bezier(0.34, 1.56, 0.64, 1)`）。
  - **触觉按压反馈 (Tactile Depression)**：按钮与控件 `:active` 时具有真实物理下沉（`scale(0.97)`），图标按钮平滑弹缩。
  - **核心播放/暂停键**：圆形 44px 悬浮强调按钮，带有专属光晕阴影，播放三角光学居中，支持 Hover 微缩放与按压回弹。
  - **滑动进度条 (Seek Slider)**：鼠标移入时音轨平滑增宽，滑块带弹簧放大与高亮外圈发光。
  - **字幕列表 WinUI 胶囊指示条**：当前激活句子左侧呈现 22px 圆角垂直胶囊 Pill 指示条，跳句时带有平滑弹性缩放展开。
  - **流畅折叠动画 (WinUI Expander)**：【题前提示】与【重复朗读】展开收起告别生硬闪现，采用 300ms 丝滑高度与透明度渐变，箭头平滑旋转 90°。
  - **挖空揭示微动效 (Cloze Reveal Pulse)**：单词揭示时触发自然的轻微缩放脉冲动效。
  - **亚克力浮窗与弹窗 (Acrylic CommandBar Flyout)**：暂停操作浮窗与阻断协议弹窗具备 28px 高斯模糊与 180% 色彩饱和度提升，浮现时具备飞入缩放动画。
  - **Windows 11 纤细自动渐隐滚动条**：8px 极简悬浮滚动条，悬停高亮，自然贴合桌面系统体验。
- **暗黑 / 明亮模式**：支持一键切换暗黑模式与明亮模式，自动跟随系统偏好。
- **完整复刻的布局**：
  - **桌面端 (>860px)**：经典双栏分屏（左侧 100 权重题目与控制台，右侧 168 权重字幕审阅面板）。
  - **移动端 (≤860px)**：顶部导航栏自适应切换【题目练习】、【听力字幕】与【上下分屏】，并在底部常驻轻量化悬浮播放条，阅读字幕时也可一键控制单句循环、暂停、上一句/下一句。

### 2. 原生 ILP 精听包解析与播放
- **无需后端服务器**：纯前端解压并解析 `.ilp` (ZIP) 格式精听包。
- **Manifest 解析**：支持 `manifest.json` 标准格式，自动关联课程元数据、UUID、版本号与时长。
- **SRT 字幕同步**：高精度解析 `transcript.srt` 字幕时间轴，播放过程实时高亮并平滑滚动跟随当前句。
- **练习题系统**：
  - 自动归类材料与题目（`第 X 题`、`听力材料`、`题前提示`）。
  - 题目选项单选与答案一键显示/隐藏。
  - 底部题目索引横向滑动条（`题目索引`），点击题号直接跳转对应听力材料。
- **挖空精听 (Cloze)**：
  - 支持高斯模糊遮罩（Gaussian Blur）单词挖空。
  - 点击单个挖空单词单独显示/隐藏。
  - 支持“显示全部挖空”与“显示本段挖空”批量控制。
- **单句快速跳转与操作浮窗**：
  - **点击快速跳句子**：无论播放或暂停状态下，点击字幕列表中的任意句子均立即将音频定位至该句（更新播放进度条、当前时间及高亮句子），完全契合桌面端原版交互。
  - **暂停操作浮窗**：暂停时点击字幕即在当前句子旁弹出操作浮窗（Fluent CommandBar 悬浮条），支持【▶ 播放】、【⏯ 播放并暂停】（仅读该句后自动暂停）、【🔂 单句循环】与关闭。
  - **浮动返回原句**：如果在暂停浏览字幕时跳转到了其它句子，右上方常驻吸顶【↩ 返回原句 (时间)】悬浮卡片，一键瞬间回到原本暂停处的句子。
- **隐藏字幕模式**：勾选“隐藏字幕”后字幕整体应用高斯模糊效果，提升纯盲听精听效果。

### 3. 本地离线持久化 (IndexedDB)
- 导入的精听包音频与进度自动保存在浏览器的 IndexedDB 中。
- 刷新页面后在“最近课程”列表中继续学习，记录播放进度百分比与已揭示的挖空单词。
- 支持随时删除本地缓存课程。

### 4. 移动端专门适配
- 触摸友好的操作热区（≥ 44px）。
- 移动端三种视图模式：
  1. **题目练习**：专注于题目作答与完整播放控制。
  2. **听力字幕**：全屏阅读字幕与挖空单词，底部吸底悬浮微型播放条随时重听/暂停。
  3. **上下分屏**：类似平板与横屏设备的分屏视口。
- 支持 iOS Safe Area 底部避让。

### 5. 渐进式 Web 应用 (PWA) 与 100% 离线脱机运行
- **首次访问自动离线缓存**：集成 Service Worker (`sw.js`) 与 Cache Storage，首次加载时自动将播放器框架、CSS 样式、JS 逻辑、离线解压库、内置示例包及应用图标全部缓存到本地。
- **纯本地断网工作**：缓存完成后，后续打开应用完全**无需请求服务器**，即使拔掉网线或处于飞行模式，依然秒级秒开，随时随地精听练习。
- **支持安装为原生客户端**：
  - 符合 W3C Web App Manifest 规范，提供 192px/512px 高清与 Maskable 自适应图标。
  - 支持在 Chrome / Edge / Safari / Android / iOS 一键“安装为应用”或“添加到主屏幕”，脱离浏览器地址栏，享受原生应用般的独立窗口与桌面启动图标。
- **离线安全隔离**：离线模式下遥测请求自动静默拦截，绝不向控制台抛出任何阻断性网络报错。

### 6. 阿里云遥测与合规声明 (ARMS RUM)
- **探针集成**：已直接在页面接入阿里云性能监控探针（Browser SDK v2），启用 WebVitals 性能指标监控、API 监控、静态资源监控、JS 错误/控制台错误监听以及用户行为分析。
- **环境配置**：设置为 `prod` 环境与 `history` 路由模式，每次打开网页自动匿名上报基本客户端分辨率、视口、语言与系统运行环境。
- **全屏阻断式协议与隐私合规**：
  - 首次访问弹出**全屏阻断式**模态层（深色磨砂亚克力背景），用户必须阅读并确认勾选《用户协议》与《隐私政策及阿里云遥测声明》后方可进入应用。
  - 顶部导航栏常驻“用户协议与隐私”按钮，随时唤起双栏查阅弹窗。
  - 严格声明课程音频与学习进度 100% 留存在本地浏览器（IndexedDB），遥测绝不窃取或上传用户私有内容。

### 7. 播放前遥测检测与全屏广告拦截器阻断提示
- **播放前全自动探测**：每次触发播放动作（主播放键、迷你播放条、空格快捷键、字幕浮窗跳转、单句复读）前，系统自动探测阿里云遥测探针是否被浏览器扩展拦截。
- **离线免打扰保证**：若当前处于 PWA 离线断网环境（`navigator.onLine === false`），自动放行，绝不误判为广告拦截器。
- **全屏阻断提示弹窗**：当探测到 `aliyuncs.com` 探针脚本或日志上报通道被拦截插件（uBlock Origin、AdGuard、AdBlock Plus、Brave 盾牌等）屏蔽时，弹出全屏 Fluent Acrylic 提示层，告知用户关闭拦截器以保证音频解码与异常监控指标正常上报。
- **友好交互**：提供折叠式【白名单设置指引】、【我已关闭，重新检测并播放】动态验证按钮以及【坚持播放】自主放行选项。

## 🚀 启动与部署方式

本播放器为纯前端静态 Web 应用，无需任何服务端代码，可直接部署在任意静态托管平台：

### 方式 1：部署到 Pages（推荐，如 GitHub Pages / Cloudflare Pages）
直接将 `Web` 目录的内容推送到代码仓库或 Pages 服务即可，零依赖即开即用。

### 方式 2：Python 本地启动
在终端进入本目录运行：
```bash
cd "/Users/luyii/Documents/Development/Intensive Listening/Web"
python3 -m http.server 8089
```
然后在浏览器访问：[http://localhost:8089](http://localhost:8089)

### 方式 3：Node.js
```bash
npx serve "/Users/luyii/Documents/Development/Intensive Listening/Web"
```
