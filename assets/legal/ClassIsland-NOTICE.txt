ClassIsland 2 design and code acknowledgement

Parts of Intensive Listening's design and code draw on ClassIsland 2 (Ci2), including welcome onboarding, application notifications, settings page organization, window framing and log viewer interaction. The Intensive Listening implementation adapts these ideas and code to its own playback and course-authoring workflows.
