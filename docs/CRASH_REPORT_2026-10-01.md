# Intensive Listening 2.0 审阅滚动崩溃报告

日期：2026-10-01。分支：`2.0-dev`。用户反馈涉及 Windows 与 macOS；按最新要求，后续维护和本次交付集中于 Windows，Mac 保留现状。

## 已确认的故障

用户提供的 Windows 日志记录了两次相同的未处理异常，时间分别为 16:25:18 和 16:25:34（UTC+8）。异常为 `System.NullReferenceException`，位于 `TeacherView.BuildTranscript` 行模板，调用链经过 `ContentPresenter.ContentChanged`、`ItemsControl.ClearContainerForItemOverride`、`VirtualizingStackPanel.RecycleElement` 和布局循环。

滚动时 Avalonia 清空回收容器的内容，行模板可能收到 `null`。实现使用 `entry!.Build()`，将合法的清空过程变成了未处理异常，最终终止进程。250 句的离屏实际布局与往返滚动复现了同一堆栈。模板现在使用 `entry?.Build()`，允许空内容正常回收。

加入页面淡出后，退出工程的扩大回归又发现了一个生命周期异常：尚在淡出的旧列表延迟创建行，读取已被切换或清空的 `_editingCues`，造成索引越界。每批行现在捕获对应的字幕快照，编辑回调也检查工程归属。

两平台共用该模板和数据生命周期。Windows 日志与 macOS 离屏复现提供了定位依据；原生滚动和视觉验收由用户完成。

## 切换闪烁

原导航使用 `TransitioningContentControl`，新内容在内容更新时可见，动画在布局阶段才将其设为透明，容易出现“先看到页面，再闪一下”。新内容宿主在挂入界面前设置透明度与位移，保留旧页面到弹簧过渡结束。切换到制作列表时先准备目标状态，避免先显示旧工程再切换空列表。

## 崩溃报告功能

- 主程序未处理异常同步写入 `crash-reports/<报告ID>.json`，包含时间、平台、组件、异常类型、错误信息及托管堆栈。
- 独立监视进程识别未完成正常关闭的进程，立即启动独立报告窗口。原生异常或强制终止若未产生托管堆栈，会明确显示监视器能够获取的信息。
- 正常退出留下正常关闭标记，避免误报。后台未观察到的任务异常保存非致命报告并显示窗口。
- 未显示的报告在下次启动显示。开启遥测时自动提交未送达的报告；关闭遥测撤销待上报报告的资格，保留本地文件。
- 上报锁防止主程序和报告进程重复提交。发送结果表示原生 SDK 接受了报告，不代表 ARMS 控制台已确认入库。
- 异常文本中的常见 API Key、token 和 Authorization 值会脱敏。报告不附带设置文件、课程全文或完整日志。
- 原生遥测使用带独占租约的稳定缓存，正常关闭保留离线 SDK 队列，撤销同意时仅由缓存所有者清理。
- Windows 沿用现有 ARMS 应用。macOS 遥测按用户要求暂缓，当前版本仅保存本机报告；构建准备了官方 0.4.4 SDK。平台 AppID 与 ConfigAddress 放在 `assets/telemetry/native-rum.json`。配置为空时保留本机报告，配置就绪后补报。

## 动效

页面、制作步骤、侧栏、展开收起、弹窗、通知、按钮与选中反馈使用临界阻尼弹簧，响应参数约 0.22–0.32 秒，重定向保留当前值和速度。减少动态效果时使用较短、柔和的透明度过渡并去掉页面位移与缩放。通知期限仍为成功 5 秒、错误 15 秒。

## 安装后的 OOBE

Windows 安装器在每次成功安装后写入新的安装标识，包括覆盖安装。完成 OOBE 时记录该标识；正常重启不重复引导，重新安装后再次引导。现有设置作为引导初始值，API 密钥、主题、遥测选择和课程数据保留。取消引导不会记录完成状态，下次启动继续显示。

## 验证与交付

- 标准 Release 测试：58 项通过（Core 52、App 6）。
- 250 句离屏审阅：分题列表 15 次往返回收、挖空列表 6 次回收、题目总览返回与关闭工程通过。模板空内容崩溃和淡出期间旧行访问新字幕的越界均已回归。
- 动效：入树前透明度、导航中间帧、12 次快速反向导航、OOBE 中间帧与同意门槛、展开中途反向、选中反馈、弹窗和崩溃窗口离屏渲染通过。
- Windows 实机（10.0.0.3）：LibVLC 3.0.24 媒体检查、FFmpeg 解码切片、ILP 与工程 ZIP、独立播放器运行和原生 SDK 导出符号通过。托管异常生成完整报告，强制终止生成进程报告，正常退出不误报。
- 安装状态回归：完成标识持久化、重启无需重复引导、安装标识变化再次引导、保留现有配置通过。
- Mac 在暂停维护前已完成构建；媒体定时检查首轮曾出现暂停后定位时序失败，复跑及最终打包媒体检查通过。该记录保留供以后维护参考。

验证结果保存在 `artifacts/crash-motion/`。范围包括单元测试、实际子进程异常和强制终止、正常退出、长列表回收、挖空与返回工程、快速导航及动画中间帧、SDK 导出符号和打包媒体运行检查。最终 Windows/macOS 原生交互与遥测控制台入库由用户验收。
