# 桌面性能与课库导出

## 设置

“外观与字体”提供两个独立选项，保存后立即生效：

- 性能模式：弹簧动画直接到达目标，关闭控件属性过渡、弹窗退出截图和平滑滚动。
- 禁用动画等待（默认开启）：对话框结果立即返回，列表移除和折叠即时完成，跳过弹窗退出与欢迎动画等待；保留常规进入动画。

动画按实际帧间隔推进，低帧率时保持真实时间进度。弹窗退出截图最多使用逻辑像素分辨率。

## 性能分析

隐私页的“性能分析”默认开启，受“匿名使用情况分析”总开关控制；总开关关闭时不记录或发送性能样本。通过现有遥测通道发送 `track_timer`，每条样本只包含操作名称 `operation` 和毫秒耗时 `durationMs`。

新安装和旧设置中缺少这两个选项时使用开启的默认值；已保存的关闭选择继续保留。

- 输入样本：指针按下、按键、滚轮事件至下一次动画帧回调，以 `input.*.frame` 标识。
- 操作样本：播放操作、课程打开、制作操作、设置保存、课库导出至对应异步操作完成，包含进入操作队列的等待时间。
- 累计 500 条，或单条超过 2000 ms，提交当前批次。
- 总开关或性能分析关闭时，清空内存样本并使尚未提交的批次与在途计时失效。退出时丢弃未达阈值的样本。

## 播放与导出

打开课程时预加载播放器并定位到恢复位置，加载期间播放按钮禁用；加载失败清空媒体状态并显示错误。

最近课程每个条目提供“导出精听包”。导出课库当前的 manifest、音频和字幕，保留 UUID、包版本、题目、挖空和制作者信息。播放进度与答题记录保存在本机进度文件中。导出包可重新导入；相同 UUID 使用现有替换确认流程。

## 回归用例

- `AsrNoSpeechTests`：嵌套无语音响应恢复为空字幕，鉴权及模型参数错误继续失败。
- `PerformanceAnalysisTests`：500 条批次、2 秒慢操作、同意状态与设置往返。
- `IlpLibraryExporterTests`：导出后重新导入、元数据与媒体保持、导出位置约束。
- `StudentPlaybackTests`：预加载、首次播放复用引擎、加载失败及再次打开恢复。
