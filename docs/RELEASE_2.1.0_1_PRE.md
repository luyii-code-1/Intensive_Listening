# Intensive Listening v2.1.0(1) 预发布

本版本提供更新后的 Windows 客户端安装包、便携包和 MDN 服务端。发布标签为 `v2.1.0(1)-Pre`，程序集及 MDN 更新任务使用数值版本 `2.1.0.1`，应用展示版本为 `2.1.0(1)`。

## MDN

- 管理员可设置设备别名，原设备名和 UUID 保留，支持共同搜索。
- 首页设备列表显示实时连接延迟或上次轮询时间，每 5 秒刷新。
- 遥测与诊断按中文字段展示，支持搜索设备、版本和诊断内容，按设备与事件筛选，以及分页查询。
- 更新下发支持按设备查询接收、下载进度、等待安装、关窗后安装、安装中、成功和失败状态。历史记录可清理，当前任务保留；失败设备可单独重新下发。

## 客户端

- 每道选择题的显示答案按钮直接在原选项标记正确项和错选项，再次点击隐藏反馈，支持继续改选。
- OTA 静默下载并校验。窗口打开时，应用内倒计时 10 秒后保存并安装，完成后恢复窗口并跳过 OOBE。用户选择延后时，关闭窗口即保存并开始安装，完成后保持关闭。
- 后台 OTA 完成后保持后台状态。安装阶段使用 Windows UAC，由用户确认，取消后上报失败并等待管理员重试指令。
- 冷更新先后台下载，完成后通过 Windows 通知及应用内弹窗提供手动安装入口。弹窗支持更新和稍后，并跳转设置的更新区域。
- 更新欢迎页显示“已成功更新到 v2.1.0(1)”。更新安装程序显示名称为“Intensive Listening更新”。

## 修复与诊断

- 字幕绑定失败保留工程和识别结果，继续加载其他工程；转写前及恢复结果时刷新音频实际时长。
- Crash 使用 `error_track` 事件上报。
- Release 调试符号使用 `/_/` 虚拟源码路径，保留文件名和行号。

## 验证

发布前完成 Windows Release 编译、客户端与核心自动测试、MDN 自动测试、运行依赖和调试符号检查。UI 交互、Windows 通知点击及真实 UAC 更新流程由用户验收。
