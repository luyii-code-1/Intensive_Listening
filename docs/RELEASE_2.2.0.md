# Intensive Listening 2.2.0

## 云端生成字幕

- Desktop 将录音上传至云服务，由服务器完成处理并返回字幕，界面持续显示上传和生成进度。
- 支持上传中断后继续、重新打开应用后恢复任务，以及失败后的重试。
- 新版 Desktop 云任务按录音总时长向上取整，每分钟 0.5 积分；成功完成后结算，失败或主动取消释放本次冻结积分。
- 云服务管理后台可查看任务、处理进度和结算记录，并进行终止与重试操作。

## 使用体验

- 改进窄窗口下的页面布局、播放与字幕区域分配，以及设置页操作区的排列。
- 完善首次使用说明和帮助入口，以“选择录音”“自动生成字幕”等易懂文案引导制作。
- 制作页开始按钮与图标、标题居中对齐。
- 新增性能模式、禁用动画等待和性能分析选项。禁用动画等待、性能分析默认开启；性能分析受匿名使用情况分析总开关控制，已保存的关闭选择保留。
- 支持从本机课程库导出课程包，保留课程内容和制作信息。

## 稳定性与兼容

- 改进工程保存、导出失败保护、学习进度保存及异常记录恢复。
- 改进云课程下载、云任务恢复、取消确认及重复请求处理。
- 完善组织管理下的云账号、字幕生成权限、学生端限制和任务状态衔接。
- 保留旧课程包、制作项目和已有任务的兼容处理。

## 安装与升级

Windows x64 使用安装程序；macOS Apple Silicon 使用 DMG。升级前可备份个人课程和制作项目，覆盖安装保留用户数据。
Windows 的托盘、文件关联、组织安装程序分发及独立 EXE 播放器按 Windows 平台能力提供。
macOS 包的实际最低系统版本与签名状态以构建产物及下载说明为准。
