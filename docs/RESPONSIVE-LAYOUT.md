# 桌面响应式布局

适配范围：最小窗口 720×560，常规桌面窗口与 125%–200% 系统缩放。尺寸使用 Avalonia 逻辑坐标。

- 共享操作行使用 WrapPanel 的 ItemSpacing、LineSpacing 管理间距，保留子控件原有 Margin。
- ResponsivePair 按实际可用宽度及操作区所需宽度决定横排或上下排列，窗口放大后恢复横排。用于设置行、页头、快捷键设置、云端课程、关于信息和队列标题。
- 组织管理包装层使用 Grid，内容参与正常尺寸分配，管理说明按可用宽度换行。
- 设置导航在窄宽度下改为顶部换行分类，API 配置字段与字体选项按可用宽度重排。
- 制作页根据页面实际宽度调整布局，小于 900 时使用项目列表或编辑区单页；编辑时用返回按钮回到列表。审阅工具栏和底部操作允许换行。
- 播放器窄布局为播放区分配最多 55% 高度，字幕保留剩余高度；播放控件使用自然尺寸换行。控件区域超出可分配高度时可滚动。
- 课程条目使用最小高度，自然增长以容纳内容；标题使用剩余宽度。
- 弹窗沿用已有的窗口尺寸限制与滚动策略。

参考 ClassIsland 2 通用设置页的设置分组与内容布局组织方式：
https://github.com/ClassIsland/ClassIsland/blob/2.0/ClassIsland/Views/SettingPages/GeneralSettingsPage.axaml

ResponsiveLayoutTests 覆盖操作区在宽窄之间往返重排、播放器与字幕在多种尺寸下占用正尺寸且不超出布局边界。视觉对齐与真实 DPI 下的交互由用户验收。
