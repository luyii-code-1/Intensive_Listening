## 用户验收路线

1. 首次安装后按默认选项完成向导，确认能看懂登录与转写配置的用途。
2. 没有课程时查看使用指南，选择精听包；确认指南关闭后才出现文件选择与后续导入提示。
3. 导入普通音频并播放，确认能理解录音本身没有逐句字幕。
4. 从指南进入制作页，选择音频建立项目；确认此操作停在转写步骤，由用户选择后续处理。
5. 在 Web 首页加载示例，播放、切句和循环；再导入自己的课程，并从最近课程继续。
6. 检查窄窗口及手机页面上的按钮、说明和教程导航；同时验收组织管理限制下的入口状态。
