# 从音频制作课程

左侧点「制作」进入课程项目，右上角「新建项目」开始。按「音频 → 转写 → 审阅 → 完成」推进。

## 新建项目，选择制作方式

**👉️ 点右上角红色「新建项目」，在对话框里选择「人工制作」。**

<figure class="shot shot--dialog">
  <img src="./assets/guide/authoring-mode.png" alt="新建项目对话框：选择智能体制作或人工制作" loading="lazy">
  <span class="shot-pin flip" style="--x:66%;--y:70%"><span class="shot-pin-label">人工制作</span></span>
  <figcaption>对话框默认突出「智能体制作」，人工制作在右侧。</figcaption>
</figure>

## 绑定音频

**👉️ 点「选择音频」，选中 MP3、M4A 或 WAV。** 音频会复制到工程目录，之后可以随时退出再继续。已有字幕时直接点「导入 SRT」。

<figure class="shot">
  <img src="./assets/guide/teacher-audio.png" alt="课程项目的音频步骤：选择音频与导入 SRT" loading="lazy">
  <span class="shot-pin" style="--x:58%;--y:62%"><span class="shot-pin-label">选择音频</span></span>
  <figcaption>红色按钮是主操作；「导入 SRT」会直接跳到审阅。</figcaption>
</figure>

## 转写或导入字幕

**👉️ 点「开始转写」，等任务完成后回到工程点「载入字幕」。**

<figure class="shot">
  <img src="./assets/guide/teacher-transcribe.png" alt="课程项目的转写步骤：开始转写、导入 SRT、更换音频" loading="lazy">
  <span class="shot-pin" style="--x:58%;--y:62%"><span class="shot-pin-label">开始转写</span></span>
  <figcaption>三个按钮分别是云端转写、导入字幕和更换音频。</figcaption>
</figure>

## 校对原句与题目

**👉️ 播放音频，逐句修正文字和时间点，再填写题目、选项和答案。**

<figure class="shot">
  <img src="./assets/guide/teacher-review.png" alt="审阅界面：逐句原文与题目" loading="lazy">
  <figcaption>句子左侧的「第 1 题」表示它属于哪道题；右上角可切换题目总览。</figcaption>
</figure>

::: tip 校对时的顺序
先改字（错字、断句、时间点），再分题（把句子归入材料），最后填题目和答案。改完记得点右下角「保存」。
:::

## 设置挖空

**👉️ 点「下一步：设置挖空」，再点英文单词把它设为挖空。** 标点不参与分词，重复朗读区间会同步同一处挖空。

<figure class="shot">
  <img src="./assets/guide/teacher-cloze.png" alt="设置挖空界面：逐词显示，可点击单词设为挖空" loading="lazy">
  <figcaption>再点一次可以取消挖空；右上角「返回题目」回到审阅。</figcaption>
</figure>

## 保存并交付

1. **👉️ 点右下角「保存」。**
2. **👉️ 保存成功后，底部会出现「导出为精听包」与「添加到播放」。**
3. **👉️ 点「导出为精听包」生成 `.ilp`，发给学生。**

::: warning 看不到导出按钮？
先点「保存」。之后又改了字幕或题目，需要再保存一次，交付按钮才会重新出现。
:::

**🎉 完成标志：** 拿到可分享的 `.ilp` 文件，或在本机课程列表里看到它。
