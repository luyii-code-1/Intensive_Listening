# 人工制课

在「制作」中点击「新建项目」，选择「人工制作」，按「音频 → 转写 → 审阅 → 完成」推进，底部进度条显示当前阶段。

## 新建项目并选择制作方式

点右上角红色「新建项目」，在弹出的对话框里选择「人工制作」，之后可以修改课程标题。

![新建项目对话框：选择智能体制作或人工制作](https://il.luyii.cn/assets/guide/authoring-mode.png)

对话框把常用方式放在主按钮位置，人工制作在右侧。

**完成标志：** 出现空白工程，进入「音频」步骤。

## 绑定音频

在「音频」步骤点「选择音频」，选中 MP3、M4A 或 WAV。音频会复制到工程目录，之后可以随时退出再继续。已有字幕时可直接点「导入 SRT」。

![课程项目的音频步骤：选择音频与导入 SRT](https://il.luyii.cn/assets/guide/teacher-audio.png)

红色「选择音频」是主操作；「导入 SRT」会直接进入审阅。

**完成标志：** 工程显示已绑定音频，进度进入「转写」。

## 生成或导入字幕

点「开始转写」把任务加入队列，或用「导入 SRT」载入已有字幕。转写完成后回到工程，点击「载入字幕」。

![课程项目的转写步骤：开始转写、导入 SRT、更换音频](https://il.luyii.cn/assets/guide/teacher-transcribe.png)

三个按钮分别是云端转写、导入字幕和更换音频。

**完成标志：** 出现逐句字幕与时间轴。

## 校对原句与题目

播放音频，逐句修正文字和时间点，必要时合并或拆分句子。用「选择整段」把句子归入材料，填写题号、题干、选项和答案，并绑定音频区间；「题目总览」可以一次检查所有小题。

![审阅界面：左侧工程列表，中间逐句原文与题目分组，右上角题目总览](https://il.luyii.cn/assets/guide/teacher-review.png)

句子左侧的「第 1 题」表示它属于哪道题；右上角可切换题目总览。

**完成标志：** 题目、答案与对应句子核对完成，底部点「保存」。

## 设置挖空

点「下一步：设置挖空」进入挖空编辑。点击英文单词把它设为挖空，标点不参与分词；同一材料的重复朗读区间会同步对应挖空。

![设置挖空界面：逐词显示，可点击单词设为挖空](https://il.luyii.cn/assets/guide/teacher-cloze.png)

被点选的词会成为学生听到的挖空词，再点一次可取消。

**完成标志：** 目标词以挖空状态显示。

## 保存并交付

确认内容后点右下角「保存」。保存成功后，底部出现「导出为精听包」与「添加到播放」；继续编辑后需要再次保存，导出按钮才会重新出现。

![课程项目底部：保存按钮与完成后出现的交付操作](https://il.luyii.cn/assets/guide/teacher-delivery.png)

先保存，再导出或加入播放列表；左侧工程状态会变成「已完成」。

**完成标志：** 取得可分享的 `.ilp` 文件，或在本机课程列表中看到它。
