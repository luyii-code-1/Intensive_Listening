# 常见问题

### 转写提示「API 未配置」

检查「设置 → 制作与智能体 → API 设置」中的 Key、Endpoint 与模型是否属于同一地域，保存后重试。已有匹配 SRT 时可直接导入字幕。

### 点击「保存」后没有出现「导出为精听包」

导出按钮仅在工程状态为「已完成」且没有未保存修改时出现。重新点击「保存」后再查看底部操作区。

### 智能体无法开始制作

确认 MCP 已启用、客户端使用应用复制的配置，并已发送操作提示。首次接管需在应用内批准；授权状态可在 MCP 设置中查看或撤销。

### macOS 首次启动被系统阻止

当前 DMG 未经过 Apple 公证。请在「系统设置 → 隐私与安全性」中允许打开，或从[正式版 Release](https://github.com/luyii-code-1/Intensive_Listening/releases/latest)重新获取安装包。

### 界面与文档截图不一致

文档按当前版本界面编写。若按钮名称或位置不同，请先确认应用版本；仍无法对应时，请在[问题反馈](https://github.com/luyii-code-1/Intensive_Listening/issues)附上截图说明。
