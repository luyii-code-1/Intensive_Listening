# 常见问题

## 下载完了，下一步点哪里？

先打开下载的安装程序，安装完成后启动 Intensive Listening。有老师发来的 .ilp 文件，就在播放首页点「导入精听包或音频」；只有录音也可以直接导入播放。需要制作逐句字幕时才进入「制作」。还没有文件时，可先[体验示例课程](./web-player)。

## 导入 MP3 后为什么没有字幕和题目？

MP3 只含声音。请到「制作 → 新建项目 → 人工制作」选择音频，然后转写或导入对应的 SRT 字幕。校对保存后点「添加到播放」，即可逐句练习。

## 播放课程一定要登录或填写 API Key 吗？

播放本地精听包或普通音频可以直接开始。云服务登录用于访问云端课程及云端转写；自己的 API Key 用于自备接口转写。第一次使用时可先跳过转写配置。

## 转写提示 API 未配置

按[百炼配置步骤](./transcription)核对地址、模型和 Key，保存后重试。已有与音频对应的 SRT 时，可直接导入字幕。

## 点了「保存」，还是看不到「导出为精听包」

保存成功后底部才会出现导出与「添加到播放」；如果之后又改了字幕或题目，需要再保存一次。工程状态显示「已完成」时才可以交付。

## 智能体无法开始制课

确认 MCP 已启用，客户端使用应用复制的配置，并已发送操作提示。首次接管还需要在应用内批准；授权状态可在 MCP 设置中查看。

## macOS 首次打开受到系统拦截

当前 DMG 采用 ad-hoc 签名。尝试打开应用后，在「系统设置 → 隐私与安全性」找到「仍要打开」，按系统提示确认。请从本网站或[正式版 Release](https://github.com/luyii-code-1/Intensive_Listening/releases/latest)获取安装包；操作路径参见[Apple 官方说明](https://support.apple.com/zh-cn/102445)。
