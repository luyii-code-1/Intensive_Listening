# 常见问题

### 转写提示 API 未配置

按[配置阿里云百炼转写](./transcription)核对地址、模型和 Key，保存后重试。已有与音频对应的 SRT 时，可直接导入字幕。

### 点了「保存」，还是看不到「导出为精听包」

保存成功后底部才会出现导出与「添加到播放」；如果之后又改了字幕或题目，需要再保存一次。左侧工程状态显示「已完成」时才可以交付。

### 智能体无法开始制课

确认 MCP 已打开，客户端使用的是应用里复制的配置，并且已经发送操作提示。首次接管还需要在应用内批准；授权状态可在 MCP 设置中查看。

### macOS 第一次打开被系统拦截

当前 DMG 采用 ad-hoc 签名。尝试打开应用后，在「系统设置 → 隐私与安全性」找到「仍要打开」，按系统提示确认。请从本网站或[正式版 Release](https://github.com/luyii-code-1/Intensive_Listening/releases/latest)获取安装包。

### 找不到按钮或界面和截图不一样

本教程按当前版本界面整理。如果按钮名称不同，先看应用是否已更新；也可以在[反馈页面](https://github.com/luyii-code-1/Intensive_Listening/issues)附上截图说明。
