# 首次运行

首次启动会在主窗口中依次显示 8 个设置页面，从许可条款到转写接口。主题、按键等设置可以先保持默认；云服务可选择「暂时跳过」，API Key 可留空。之后都可以在「设置」里修改。

## 同意许可条款

分别勾选用户协议与隐私说明，两项都勾选后「下一步」才可用。

![首次运行：同意许可条款页](https://il.luyii.cn/assets/guide/first-run-license.png)

两类条款分别勾选，底部箭头进入下一步。

## 基本设置

设置是否关联 `.ilp` 文件、是否开启 MCP 制作接口、是否跳过题前提示、导入音频时是否自动建立项目，以及是否发送匿名数据。建议保留「关联 .ilp 文件」，之后双击课程包就能直接打开。

![首次运行：基本设置页的开关列表](https://il.luyii.cn/assets/guide/first-run-basics.png)

每个开关右侧都有说明，拿不准时保持默认。

## 快捷按键

给播放、上一句／下一句、上一题／下一题录制单键，翻页笔的 PageUp / PageDown 也可以。暂时不设置不影响使用。

![首次运行：快捷按键设置页](https://il.luyii.cn/assets/guide/first-run-keys.png)

按键只在应用前台的播放页生效。

## 外观与云服务

选择浅色／深色主题和字幕字号；云服务页可以直接点「暂时跳过」，登录后才有云端课程与云端转写。

![首次运行：云服务页，可以暂时跳过](https://il.luyii.cn/assets/guide/first-run-cloud.png)

云服务不是必需项，稍后可以再登录。

## 转写接口与完成

填写阿里云百炼 API Key，或勾选「使用云服务提供的接口」；也可以留空稍后再配。最后一页点「完成设置」，进入播放页。

![首次运行：转写接口页，API Key 可以留空](https://il.luyii.cn/assets/guide/first-run-asr.png)

留空也可以，开始转写前再配置。
