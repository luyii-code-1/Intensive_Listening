# 快速上手

装好桌面应用后，先选一件你想做的事。第一次运行的主题、按键等选项可以先保持默认；播放已有精听包和普通音频均可直接开始。

手里有 .ilp 文件

## 打开老师发来的课程

1. 把老师发来的 `.ilp` 文件保存到电脑，记住保存位置。
2. 点「导入精听包或音频」，选中这个文件。
3. 导入后点击播放；用「上一句／下一句」定位，开启「单句循环」反复听。

 [学生练习说明](./listening)

手里只有 MP3 等录音

## 播放录音，或给它制作字幕

1. 只想听录音：在播放首页点「导入精听包或音频」，选中音频后播放。
2. 想逐句听：左侧点「制作 → 新建项目 → 人工制作」，选择音频。
3. 转写或导入已有 SRT 字幕，校对后保存，再点「添加到播放」。

 [制课说明](./authoring)

## 先用示例体验一次

1. 打开 Web 播放器，点「加载示例课程」。
2. 点击播放，再试「下一句」和「单句循环」。
3. 熟悉后，导入自己的精听包或使用桌面版制作课程。

 [浏览器体验说明](./web-player)

**文件名怎么看？**`.ilp` 是已经制作好的精听课程，通常包含音频、字幕和题目；MP3、M4A、WAV 是普通音频；`.srt` 是字幕，需要搭配对应音频使用。文件一般保存在「下载」文件夹，或你在聊天软件中选择的保存位置。
