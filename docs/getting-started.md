# 快速开始

根据材料与目标选择路径。制作课程推荐使用智能体，人工制作适合需要逐句精修的情况。

## 路径一：制作课程（推荐智能体）

先准备一个本机 AI 助手（如 WorkBuddy）。应用通过 MCP 与它连接，按下面步骤复制配置即可。

1. 在「制作」中点击「新建项目」，选择「智能体制作」。
2. 选择音频，按需加入试卷或听力原文。
3. 在「设置 → 制作与智能体」启用 MCP，复制配置与操作提示。
4. 在智能体客户端发送提示词，应用内批准接管。
5. 智能体交还后审阅字幕、题目与挖空，保存并导出 `.ilp`。

详细步骤见[智能体制课](./agents)。

## 路径二：人工制作

1. 在「制作」中新建项目，选择「人工制作」。
2. 在「音频」步骤绑定录音。
3. 转写或导入 SRT，逐句校对并编排题目。
4. 设置挖空，保存后导出 `.ilp`。

详细步骤见[人工制课](./authoring)。

## 路径三：播放已有课程

1. 在播放页点击「导入精听包或音频」。
2. 选择 `.ilp` 文件。
3. 使用「上一句」「下一句」「单句循环」进行练习。

详细步骤见[导入并播放课程](./listening)。

::: tip 文件类型
`.ilp` 是课程包；MP3、M4A、WAV 是普通录音；`.srt` 是字幕文件，需与对应录音配合使用。
:::
