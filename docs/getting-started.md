# 第一次使用

先按手里的文件选一条路线，每条路线都只需要几步。

## 手里有 `.ilp` 课程

1. **👉️ 把老师发来的 `.ilp` 保存到电脑**，记住保存位置。
2. **👉️ 打开应用，点「导入精听包或音频」**，选中这个文件。
3. **👉️ 点播放，用「上一句／下一句」定位**，需要时开「单句循环」反复听。

路线详情：[打开课程，逐句精听](./listening)

## 手里只有录音

1. **👉️ 直接听**：在播放页点「导入精听包或音频」，把录音导进来就能播放。
2. **👉️ 想逐句精听**：左侧点「制作」，新建项目并选择录音，转写或导入 SRT 后保存。
3. **👉️ 校对后保存**，再点「添加到播放」或「导出为精听包」。

路线详情：[从音频制作课程](./authoring)

## 手里什么都没有

1. **👉️ 打开 Web 播放器**，点「加载示例课程」。
2. **👉️ 点播放，再试「下一句」和「单句循环」**，熟悉逐句精听的操作。
3. **👉️ 熟悉后安装桌面版**，导入自己的课程或开始制作。

路线详情：[在浏览器里试听](./web-player) · [安装桌面应用](./installation)

::: tip `.ilp` 是什么？
`.ilp` 是已经制作好的精听课程，一般包含音频、字幕和题目；MP3、M4A、WAV 是普通录音；`.srt` 是字幕，需要搭配对应的音频使用。
:::
