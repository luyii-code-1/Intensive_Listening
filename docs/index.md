# 使用文档

Intensive Listening 把一段录音变成可以逐句精听的课程：老师把音频、试卷和原文整理成 `.ilp`，学生在同一份课程里按题、按句反复听。

::: tip 这套教程怎么读
第一次使用，建议按「第一次使用」里的顺序读完。每当看到 **👉️**，就说明这里需要你动手点一下；其他内容只供参考。
:::

## 你的情况

| 你手里的东西 | 从这里开始 |
| --- | --- |
| 老师发来的 `.ilp` 课程 | [打开课程，逐句精听](./listening) |
| 一段 MP3、M4A 或 WAV 录音 | [从音频制作课程](./authoring) |
| 还没有课程，想先体验 | [在浏览器里试听示例课程](./web-player) |
| 刚下载安装包 | [安装桌面应用](./installation) |
| 遇到报错或找不到按钮 | [常见问题](./faq) |

## 第一次使用

**👉️ 从[安装桌面应用](./installation)开始，安装完成后跟着[首次运行](./first-run)完成设置。**

装好之后，应用里只有三件事：**播放**用来听课程，**制作**用来做课程，**设置**用来调整习惯。

## 制作一节课程

1. **👉️ 选择音频，新建项目**：[从音频制作课程](./authoring)
2. **👉️ 选择转写服务或导入 SRT**：[配置转写](./transcription)
3. **👉️ 校对字幕和题目，保存后导出 `.ilp`**：[校对与交付](./authoring#校对原句与题目)

::: tip 想交给智能体做？
应用到「设置 → 制作与智能体」开启 MCP，让本机智能体读取材料并整理初稿，你再审阅保存。见[智能体制课](./agents)。
:::
