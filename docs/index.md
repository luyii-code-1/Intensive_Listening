# 使用文档

Intensive Listening 用于制作和练习英语精听课程。教师把音频、试卷或原文整理成 `.ilp` 精听包，学生在播放页逐句训练。

## 选择入口

| 当前情况 | 建议阅读 |
| --- | --- |
| 需要从录音制作课程 | [智能体制课（推荐）](./agents) |
| 需要自行逐句编辑 | [人工制课](./authoring) |
| 已收到 `.ilp` 精听包 | [导入并播放课程](./listening) |
| 尚未安装应用 | [安装桌面应用](./installation) |
| 需要生成字幕 | [配置转写服务](./transcription) |
| 需要先在浏览器体验 | [Web 播放器](./web-player) |

## 推荐流程

制作课程推荐使用智能体：智能体读取材料并整理字幕、题目与挖空初稿，教师在应用内批准接管、审阅并导出，可显著减少逐句录入。

智能体是电脑上的 AI 助手程序（如 WorkBuddy）；MCP 是应用与它之间的连接方式，按教程复制配置即可。

1. [安装桌面应用](./installation)。
2. 启动应用，完成[首次运行](./first-run)的 8 个设置页。
3. [配置转写服务](./transcription)（需要自动字幕时）。
4. 按[智能体制课](./agents)完成初稿，再人工审阅并导出。
5. 学生按[导入并播放课程](./listening)开始练习。

::: tip 术语约定
- **课程工程**：制作页中尚未导出的课程项目。
- **精听包**：扩展名为 `.ilp` 的课程文件，包含音频、字幕、题目和挖空。
- **播放页**：学生练习界面；**制作页**：教师编辑界面。
:::
