# 使用文档

Intensive Listening 帮助你逐句听懂录音，也可以把音频制作成带字幕和题目的精听课程。

## 你想先做什么？

| 手里的材料或目标 | 从哪里开始 |
| --- | --- |
| 老师发来的 `.ilp` 课程 | [导入并播放课程](./listening) |
| 一份 MP3、M4A 等录音 | [播放录音或制作字幕](./getting-started) |
| 还没有课程，想先试试 | [体验 Web 示例课程](./web-player) |
| 想安装桌面应用 | [安装与准备](./installation) |
| 转写或播放时遇到问题 | [常见问题](./faq) |

## 第一次使用

从[快速上手](./getting-started)开始，按你手里的文件选一条路线。每篇文档右侧有本页目录，左侧可切换主题；也可以在顶部搜索“导入”“字幕”或“云服务”。

播放本地精听包或普通录音可以直接开始；从录音生成字幕时，再选择[转写服务](./transcription)。

## 制作一份课程

1. [选择音频，建立项目](./authoring)。
2. [转写](./transcription)或导入已有的 SRT 字幕。
3. [校对字幕、题目并保存导出](./authoring)。
