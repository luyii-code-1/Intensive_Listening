# 安装与准备

教师制作与学生练习都在 Intensive Listening 桌面应用中完成。

| 项目 | 说明 |
| --- | --- |
| Windows | 从[下载区](https://il.luyii.cn/#download)取得安装程序，双击运行并选择安装目录，装完从开始菜单或桌面启动；首次启动会打开设置向导。 |
| macOS | 下载 DMG，把应用拖入 Applications。首次打开若被系统拦截，在「系统设置 → 隐私与安全性」选择「仍要打开」；参见[Apple 官方说明](https://support.apple.com/zh-cn/102445)。 |
| 材料 | 人工制课至少需要一段 MP3、M4A 或 WAV 音频；试卷、答案、听力原文和已有 SRT 可帮助校对。智能体制课可附加多份 DOCX 或文字版 PDF。 |
| 学生 | 从教师处取得 `.ilp` 精听包即可练习，不需要配置转写。 |
