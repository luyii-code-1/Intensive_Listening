# 安装桌面应用

教师制作和学生练习都在 Intensive Listening 桌面应用中完成。

## 检查系统

::: warning 安装前先确认
应用只提供 Windows 10/11 x64 与 macOS 26.0+（Apple Silicon）两个版本。Intel Mac 和 32 位 Windows 无法运行。
:::

## 下载并安装

### Windows

1. **👉️ 打开[下载页](https://il.luyii.cn/#download)，下载 Windows 安装包。**
2. **👉️ 双击安装包**，选择安装目录，按提示完成安装。
3. **👉️ 从开始菜单或桌面启动应用**，首次启动会打开设置向导。

### macOS

1. **👉️ 下载 DMG，双击打开，把应用拖进 Applications。**
2. **👉️ 在启动台打开应用。** 如果系统提示「无法验证开发者」，到「系统设置 → 隐私与安全性」点「仍要打开」。

::: tip 系统拦截是正常的
当前 macOS 安装包未经过 Apple 公证，第一次打开会被拦截一次，允许后即可正常使用。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。
:::

## 准备好材料

- **录音**：MP3、M4A 或 WAV。
- **参考材料**：试卷、答案、听力原文，推荐 DOCX 或文字版 PDF。
- **字幕**：已有 SRT 可以直接导入，不用配置转写。

**👉️ 安装完成后继续[首次运行](./first-run)。**
