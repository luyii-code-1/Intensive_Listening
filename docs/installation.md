# 安装桌面应用

桌面应用是课程制作与练习的完整环境。安装前确认系统版本与架构满足要求。

## 系统要求

| 平台 | 要求 |
| --- | --- |
| Windows | Windows 10/11，x64 |
| macOS | macOS 26.0 及以上，Apple Silicon |

不满足上述条件时，可先使用 [Web 播放器](./web-player) 练习已有课程。

## Windows 安装

1. 打开[下载页](https://il.luyii.cn/#download)，下载 Windows 安装包。
2. 双击安装包，按安装向导选择安装目录。
3. 完成安装后，从开始菜单或桌面启动应用。

## macOS 安装

1. 下载 DMG 文件并打开。
2. 将应用拖入「Applications」文件夹。
3. 在启动台中打开应用。

::: warning macOS 首次启动
当前安装包未经过 Apple 公证，首次启动可能被系统阻止。请在「系统设置 → 隐私与安全性」中允许打开，或参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。
:::

## 准备制作材料

- 音频：MP3、M4A 或 WAV。
- 文本材料：试卷、答案或听力原文，推荐 DOCX 或文字版 PDF。
- 字幕：如已有与音频匹配的 SRT，可跳过转写配置。

安装完成后继续[首次运行](./first-run)。
