# 逐句精听

从教师处取得 `.ilp` 后即可开始。也可以打开普通音频播放；题目和挖空练习来自精听包。

## 导入课程

打开应用，点「导入精听包或音频」选择 `.ilp`。导过的课程会出现在「最近课程」，下次直接点开。Windows 关联文件后也可以双击课程包。

![播放页顶部：打开课程、导入精听包或音频、最近课程](https://il.luyii.cn/assets/guide/student-open.png)

红色「导入精听包或音频」是主要入口，「打开课程」用于本机已有课程。

## 按题或按句定位

左侧是题目和选项，右侧是逐句时间轴。使用「上一题／下一题」跳题，「上一句／下一句」逐句移动，也可以直接点句子；当前句会高亮。

![播放页：右侧逐句字幕，当前句高亮，左侧题目](https://il.luyii.cn/assets/guide/student-loaded.png)

播放中高亮会自动跟随当前句；点击任意句可定位。

## 循环、盲听与核对

勾选「单句循环」反复听当前句；勾选「隐藏字幕」做盲听。听到不确定的地方可以「重复本句」，或点「显示本段挖空」「显示全部挖空」核对拼写。

![播放页底部控件：上一题、上一句、播放、下一句、下一题，单句循环与隐藏字幕](https://il.luyii.cn/assets/guide/student-controls.png)

勾选框即时生效；「显示全部挖空」适合做完后自查。

## 接着上次继续

应用会保存每门课程的练习进度，下次打开时从上次位置继续。字幕字号与是否跳过题前提示在「设置 → 播放」里调整。
