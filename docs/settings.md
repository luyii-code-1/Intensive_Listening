# 设置与按键

设置按分类排列：外观与字体、播放、制作与智能体、数据与维护、隐私、更新、组织管理、关于。

| 项目 | 说明 |
| --- | --- |
| 外观与字体 | 选择系统字体和字重，预览文字即时更新；需要时点「恢复默认」。播放页字幕字号在「播放」分类中调整。 |
| 扩展按键 | 在「设置 → 播放 → 扩展按键」给播放／暂停、上一句／下一句、上一题／下一题、重听当前句和字幕显隐录入单键。PageUp、PageDown 适合翻页笔；按键只在应用前台的播放页生效。 |

![设置页：左侧分类导航与右侧外观字体设置](https://il.luyii.cn/assets/guide/settings.png)

设置页左侧是分类，右侧是当前分类的选项。
