## 外观与字体

1. 在「外观与字体」中选择系统字体与字重。
2. 在预览区输入文本，确认实际显示效果。
3. 点击「恢复默认」可还原默认字体设置。

播放页字幕字号位于「播放」分类。

## 扩展按键

1. 进入「设置 → 播放 → 扩展按键」。
2. 为播放/暂停、上一句/下一句、上一题/下一题、重听当前句与字幕显隐录入单键。
3. 如需清除绑定，点击对应项的重置按钮。

::: tip 生效范围
扩展按键仅在应用前台且当前页面为播放页时生效；文本输入与弹窗显示期间不会触发。
:::
