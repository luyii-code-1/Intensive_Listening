# 在浏览器里试听

不想先装桌面版时，可以用 Web 播放器直接体验逐句精听。

## 打开示例课程

1. **👉️ 打开 [Web 播放器](https://web.il.luyii.cn/)。**
2. **👉️ 点「加载示例课程」，等待课程载入。**
3. **👉️ 点播放，再试「下一句」和「单句循环」。**

## 后续

- 想继续用浏览器练习：把 `.ilp` 直接拖进页面导入。
- 想制作课程：安装[桌面应用](./installation)，见[从音频制作课程](./authoring)。

::: tip 版本说明
Web 播放器独立于桌面版发布，页面上显示的版本号以 Web 播放器为准。
:::
