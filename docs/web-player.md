# Web 播放器

Web 播放器用于在浏览器中体验逐句精听，功能与桌面播放页一致，但不包含课程制作。

## 体验示例课程

1. 打开 [Web 播放器](https://web.il.luyii.cn/)。
2. 点击「加载示例课程」。
3. 使用播放、上一句、下一句与单句循环体验练习流程。

## 使用限制

- 仅支持播放与练习，不支持制作、转写与导出。
- 课程数据保存在浏览器本地，清除站点数据会丢失记录。
- 版本独立于桌面版，页面显示的版本号以 Web 播放器为准。

需要制作课程时，请安装[桌面应用](./installation)并阅读[智能体制课](./agents)。
