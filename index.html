Intensive Listening 音频播放与声音输出权限说明

为确保播放器发音清晰流畅，并适配各类移动设备与桌面浏览器的系统声音策略，特做如下说明：

一、浏览器自动播放策略 (Autoplay Policy)

现代浏览器（如 iOS Safari、Chrome、Edge）对网页音频有严格限制，禁止网页未经用户交互在后台静默出声。本播放器在您点击“播放”、“跳句”或首次进入应用时，会自动调用系统底层 AudioContext 与 HTML5 <audio> 管道，解锁浏览器音频会话。

二、系统媒体会话集成 (Media Session API)

本播放器深度适配操作系统媒体控制协议。在播放精听内容时，您可以在手机锁屏界面、系统通知中心及蓝牙耳机控制按键上直接进行播放/暂停、上一句、下一句及进度调节，无需频繁解锁屏幕。

三、常见无声音问题排查

  • iOS 实体静音开关：部分 iPhone/iPad 若机身左侧静音键处于开启状态（红点露出），可能会阻断网页音频输出。若无声音，请将拨片拨回响铃模式或插上耳机；
  • 系统媒体音量：请检查设备系统音量设置中的“媒体音量”（Media Volume）是否已调大；
  • 后台锁屏休眠：部分安卓定制系统可能在锁屏后杀死后台网页进程，推荐通过浏览器菜单中的“安装应用 / 添加到主屏幕”将本站安装为 PWA 客户端使用。

音频输出与自动播放授权说明

生效版本：2026-10-01 ｜ 适用平台：iOS Safari / Android Chrome / Windows / macOS

一、现代浏览器音频播放机制

现代移动端与桌面浏览器（尤其是 iOS WebKit 与 Android Chrome）对网页发声设有严格的自动播放限制策略 (Autoplay Policy)。为了防止网页静默发声骚扰用户，浏览器规定：必须获得用户的直接交互授权后，音频硬件通道方可被唤醒输出声音。

二、本播放器的权限申请与激活

当您点击下方【同意统计并继续】按钮时，系统将通过一次同步的用户交互手势，同时完成：

  • 唤醒 Web Audio 引擎：激活底层硬件音频通道（AudioContext Session），确保后续点句、循环、挖空朗读随时发声；
  • 注册系统媒体会话 (Media Session)：支持在手机锁屏、通知中心与蓝牙耳机上直接控制播放、暂停与跳句；
  • 零隐私风险：所有的音频播放完全在本地离线解码，绝不索取麦克风录音权限，也绝不向外网传输任何录音数据。

三、移动设备无声排查指引

如果您在播放过程中听不到声音，请检查以下设备设置：

  • iOS 物理静音开关：iPhone 机身左侧若拨动至橙色静音状态，部分 iOS 版本可能会将网页声音静音，请拨回响铃模式或插上耳机；
  • 系统媒体音量：请确认手机或电脑的“媒体音量”已调至合适大小（而非仅铃声音量）。
